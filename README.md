# Library Management System (C++)

A console-based Library Management System built using C++.

## Features

- Login System
- Add Book
- Show All Books
- Search Book
- Issue Book
- Return Book
- Fine Calculation System
- Delete Book
- Update Book
- File Handling

## Default Login

Username: admin  
Password: 1234

## How to Run

### Method 1: Online Compiler

1. Open Programiz C++ Compiler
2. Copy the code from `library_management_system.cpp`
3. Paste the code
4. Click Run

### Method 2: VS Code / Dev C++

1. Download the project
2. Open `library_management_system.cpp`
3. Compile and Run the code
